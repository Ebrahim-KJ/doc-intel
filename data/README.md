# Data

`documents/` and `indices/` hold uploaded files and the FAISS and BM25 indexes the app builds.

`beir/` holds the benchmark datasets (SciFact, NFCorpus, FiQA), downloaded on first run of `benchmarks/retrieval_benchmark.py`. Thakur et al. (2021), *BEIR: A Heterogeneous Benchmark for Zero-shot Evaluation of Information Retrieval Models*.
